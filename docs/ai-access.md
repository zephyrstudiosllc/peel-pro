# Peel Pro access

The October 18, 2026 product decision supersedes the separate AI subscription
plan. Monthly, yearly and lifetime purchase grant the same client Pro benefits,
including remote agent coordination, automation and notifications. The unchanged
`peel.pro.lifetime` product grants every existing lifetime owner full Pro; no
purchase-date cutoff or repurchase is required. Previously granted legacy trials
remain valid until their original three-day expiry; new legacy trials are not offered.

Free clients can stream one Mac window on flat screens or two on Vision Pro.
Audio, voice, input, basic Mac Status/current usage and local Host utilities stay
free. Pairing, explicit sharing choices, current sessions and OS permissions remain
independent requirements. Entitlement expiry prevents additional paid actions;
it does not terminate an ordinary stream or audio session.

Both Debug and Release require verified Pro access for paid features. There is
no blanket Debug preview bypass. Active verified subscriptions, supported verified
grace periods, and the existing lifetime/trial ownership policy feed the same
runtime gate. Empty or unverified responses cannot erase cached historical
lifetime ownership; explicit verified revocation can. A local cache is not proof
of entitlement to a remote Host.

See [capabilities and trust boundary](peel-2-release/entitlements.md) for the exact
matrix, and [implementation and activation checklist](peel-2-release/monetization-2026-10-18.md)
for product IDs, prices, evidence and outstanding App Store steps. AI provider
subscriptions/usage are separate from Peel Pro. No live catalog change is implied.
