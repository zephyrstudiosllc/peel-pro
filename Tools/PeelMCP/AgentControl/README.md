# Visible-window control checks

`python3 Tools/PeelMCP/AgentControl/run-checks.py` compiles the exact production wire/proof types, UDS request lifetime, lease/command policy, manual Host proof handler/predicate, client proof-handler owner scopes and session body, controller, receiver diagnostic store and input synthesizer. Only window resolution/focus, image capture, event destination and the mobile local-permission getter (for the macOS test run) are substituted. The runner verifies balanced extension scopes: legacy browser owns only its fail-closed helper and the real per-host session owns the proof emitter. It posts no desktop events, reads no screen content and changes no live settings, Keychain, TCC or devices. Temporary test outputs are removed.

Checks cover Release without an AI subscription and explicit manual consent; cryptographic separation from the existing paid proof; stale/withdrawn/old-client capability and proof generation; exact title/PID/launch/pairing/generation identities; token/inspection expiry and replay; inspected geometry/renderer replacement; immediate inspection-to-action and independent capture/input rate limits; preservation of a rate-rejected inspection; normal click/text/shortcut/scroll/drag through the real event queue; pointer mis-targeting rejection; permission/consent interruption after down with exact cleanup; local request half-close versus full disconnect. Receipt counts distinguish posted events from cleanup releases.

`python3 -m unittest discover -s Tools/PeelMCP -p 'test_*.py'` exercises the adapter and native Unix transport. It forwards the new native methods without substituting paid actions, rejects malformed/cross-action/unbounded arguments and returns the bounded native JPEG as an MCP image. The native transport fixture dispatches an echo, not a desktop action.

## Parent-owned real acceptance

`build-visible-fixture.py --output /absolute/new/path/PeelAgentControlFixture.app` builds an isolated harmless normal AppKit window; it does not launch/install it. The parent must review the actual signed candidate and permission gates before launching or sending native input. No acceptance has been performed merely by compiling this fixture.

After review, the parent may use this window instead of real Terminal or Messages content: manually open/select it in the paired client's Peel stream, enable both dedicated manual-control permissions, then list/inspect its exact window. A click increments only its counter; typing changes its empty synthetic text field; a momentary shortcut can select fixture text; scrolling moves synthetic rows; dragging moves a blue circle. Inspect after each action to verify the source result, and separately observe the receiving device. Exercise Host Stop, client permission withdrawal, background/disconnect and generation replacement with a fresh fixture request; no held input should survive. Never automatically retry an interrupted input.

The test does not certify real Accessibility focus, Screen Recording delivery, secure-input behavior, physical receiver scanout or human viewing. Vision spatial control remains unavailable without presentation telemetry. Production paid auto-launch/presentation/notify gates remain unchanged.
