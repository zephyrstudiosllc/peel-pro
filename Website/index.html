  • No paid limit on streaming window count
  • No paid resolution or session-duration limit
  • All supported manual input, including keyboard, pointer and touch

Available resolution, window count and performance still depend on the host, device, app and network. Free access keeps pairing and permissions in place.

Start with a trusted connection

Your Mac.
Your permission.

The current development targets require macOS 26.0 or later and iOS, iPadOS or visionOS 26.1 or later. Final 2.0 compatibility will be confirmed with the release.

01 · Pair

Start on the local network.

Install matching Host and client releases, then approve pairing on the Mac. Allow screen capture and the permissions needed for input.

02 · Connect

Choose the intended Mac.

Development builds support saved private-network or VPN addresses for already paired Macs. Initial pairing still needs local discovery. Peel Pro does not include a public internet relay.

03 · Authorize

Enable agent tools deliberately.

The agent bridge is opt-in. Compatible clients, paid access and action permissions need to be verified before release. Manual remote access remains part of the free plan.

Daily Mac tools stay close.

The unified Host includes SidePulse signals, CodexBar provider usage and App Mechanic system controls. Hardware support and each remote action will be documented against the devices actually tested.
